# P0-02: Config loaders with validation
Phase: 0   Owner: GPT1   Card by: setup (GPT2 to confirm)   Backlog: P0-02, F04

## Goal
Load `config/marketplaces.yaml`, `config/policy.yaml` and `config/checks.yaml` through Zod schemas so no rule or limit is ever hard-coded.

## Acceptance criteria
1. The three committed files load and validate.
2. A missing required field, a wrong type, or an unknown marketplace key fails with a message naming the file and field (one test each).
3. A profile whose `effective_date` is older than `recheck_after_days` is reported as stale (test with a fixed clock).
4. Values marked `unverified` are surfaced as unverified, not treated as true.
5. A test fails if any marketplace limit number appears hard-coded in `src/` outside the schema defaults (simple grep test).

## Out of scope / do not touch
Changing config values (GPT2 owns them via P0-05).

## Test approach
Unit tests with fixture YAML in `tests/fixtures/config/`.
