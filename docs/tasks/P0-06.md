## Acceptance criteria
1. `tests/fixtures/products/weekly-planner.json`: fictional weekly planner listing (title, description, 13 tags, price in minor units) including one over-limit and one duplicate-tag variant.
2. `tests/fixtures/hostile/`: prompt injection text, oversized text, mixed scripts and zero-width characters, path traversal file names, HTML/script in text, malformed CSV.
3. `npm run test:e2e` runs Playwright for Electron (one launch test); `npm run test:golden` runs Vitest over `tests/golden/` (empty set passes with a clear "0 cases" message, never a silent pass of real cases).
4. All fixtures fictional; a README in each fixture folder says so.
