# P0-03: Continuous integration on Windows and Linux
Phase: 0   Owner: GPT1   Card by: setup (GPT2 to confirm)   Backlog: P0-03, D-009, D-020

## Goal
Every PR runs `npm run check` on `windows-latest` and `ubuntu-latest`, so Windows behaviour is tested without Ashley.

## Acceptance criteria
1. `.github/workflows/ci.yml` runs on pull_request and push to main; uses the pinned Node version from `.nvmrc`; `npm ci` then `npm run check`.
2. Matrix covers `windows-latest` and `ubuntu-latest`.
3. No secrets, no paid features, no third-party actions beyond official `actions/*` pinned by version.
4. Handover states whether the run was observed (PASS/FAIL with link) or NOT RUN.

## Out of scope
Release or publish jobs (stop-and-ask item).
