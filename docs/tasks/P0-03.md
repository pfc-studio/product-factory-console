# P0-03: Continuous integration on Windows and Linux
Phase: 0   Owner: GPT1   Card by: GPT2   Backlog: [P0-03](../BACKLOG.md)

## Acceptance criteria
1. `.github/workflows/ci.yml` declares `pull_request` and `push` to `main`. Both jobs install the exact `.nvmrc` Node pin and run `npm ci` followed by `npm run check`.
2. A clean PR run passes on `windows-latest` and `ubuntu-latest`. The job logs show the tested revision, Node version and check result for each runner.
3. The workflow uses pinned official `actions/*` only and runs on the free tier. The workflow requires no repository secrets.
4. A deliberate failing assertion on the task branch makes `npm run check` and the CI job fail on each runner. Restore the assertion and reproduce the two green jobs. Record job links and PASS, FAIL or NOT RUN for the clean and failing runs.

## Goal
Run the existing quality check on Windows and Linux for every PR and push to `main`.

## Failure cases
Confirm a failing assertion produces a failing CI check. Give each runner time to finish so both results can be recorded.

## Out of scope
Release and publishing jobs, branch protection or access changes, and changes to the existing Windows smoke or the `npm run check` script.

## Dependencies and assumptions
